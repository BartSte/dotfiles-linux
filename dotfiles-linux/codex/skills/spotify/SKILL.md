# Spotify

Use the connected Spotify app tools and their available task-specific skills. Search for
content by text. Inspect collections when their Spotify IDs or URIs are already known.
Use now-playing tools only when Bart asks what is playing.

Create or edit a playlist, or change saved content, only when Bart requests that operation.
Recommendations alone do not authorize a library change. Do not claim that playback
started when the available integration has no playback control.

If the native Codex session does not expose the connected integration, report the specific
availability gap. Establish what is missing before starting another login flow. Do not use
the archived Hermes plugin or copy its OAuth tokens.
